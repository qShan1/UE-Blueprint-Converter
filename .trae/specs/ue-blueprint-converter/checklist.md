# Checklist

## CLI 基础
- [x] CLI 工具 `ue-bp-converter` 可通过命令行直接调用
- [x] 支持 `--input <file>` 参数从文件读取蓝图文本
- [x] 支持从 stdin 管道读取蓝图文本
- [x] 支持 `--format plain|markdown|mermaid` 参数切换输出格式（默认 plain）
- [x] 支持 `--stats` 参数输出统计信息
- [x] 支持 `--output <file>` 参数将结果写入文件

## 解析器（Parser）
- [x] 能正确识别蓝图文本中的节点声明
- [x] 能正确提取节点名称和类型
- [x] 能正确提取引脚名称、方向、类型、连接目标
- [x] 能正确提取变量引用（变量名、读写操作）
- [x] 能输出完整的中间表示（节点列表、连接列表、变量引用列表）
- [x] 对格式异常的输入能优雅降级而非崩溃

## 清洗与变换（Transformer）
- [x] 成功移除 GUID/UUID 信息
- [x] 成功移除节点坐标位置信息
- [x] 成功移除引擎内部枚举和标志位
- [x] 常见蓝图节点类型被正确映射为语义标签（Event → 事件, Branch → 分支等）
- [x] 执行流顺序被正确构建（按 Exec 引脚链排序）
- [x] 数据流依赖被正确关联（按 Data 引脚连接）

## 格式化输出（Formatter）
- [x] Plain 格式：缩进文本，逻辑清晰，每节点一行，缩进表示执行层级
- [x] Markdown 格式：包含节点清单表、连接关系表、变量使用说明
- [x] Mermaid 格式：输出合法的 `flowchart` 代码，可被 Mermaid 渲染

## 统计信息
- [x] `--stats` 输出节点总数及类型分布
- [x] `--stats` 输出分支/序列/循环节点数
- [x] `--stats` 输出变量引用数（读/写分别统计）
- [x] `--stats` 输出外部函数/事件调用数
- [x] `--stats` 可与 `--format` 配合同时输出

## 未知节点降级
- [x] 未知节点被标注 `[Unknown]` 而非丢弃
- [x] 未知节点的名称和引脚信息被保留在输出中

## 集成测试
- [x] 至少 3 个示例蓝图文件（简单事件、条件分支、含循环的复杂蓝图）
- [x] 完整 pipeline 集成测试通过
- [x] 三种输出格式均经过验证
